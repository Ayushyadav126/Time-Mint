# Time Mint — App UI

A React + Vite front-end for **Time Mint**, a digital wellbeing app that turns
focused work into spendable "Winning Time" instead of just blocking
distracting apps outright. Built from the product spec and UI design brief.

This is a **UI prototype**: all data (Winning Time balance, timers, streaks,
etc.) is currently static/sample data inside the React components. The real
tracking and app-blocking logic (which needs native Android APIs) isn't
wired up yet — this repo is for previewing and testing the interface itself.

## What was removed from the original export

The original vibe-coded export also contained: `node_modules/` (reinstalled
by `npm install`), a stale `dist/` build folder (regenerated by `npm run
build`), a `timemint.framer.ai` reference-site scrape, an `Used Icons/`
folder and `Resorces/` screenshots (unused — all icons are already inline
SVGs in `Icons.jsx`), and a few one-off Python scratch scripts used during
vibe-coding. None of these are imported by the app, so they were left out to
keep the repo small enough to drag-and-drop upload on GitHub.

## Building the APK

This repo is set up so GitHub itself builds the Android APK for you — see
the chat for the full walkthrough. Short version:

1. Push/upload this folder to a GitHub repository.
2. Open the **Actions** tab → the `Build Android APK` workflow runs
   automatically (or click **Run workflow** to trigger it by hand).
3. When it finishes, download the `TimeMint-debug-apk` artifact from the
   run's summary page — that's your installable `.apk`.

## Building locally (optional, needs Node.js + Android Studio installed)

```bash
npm install
npm run build
npm install @capacitor/core @capacitor/android
npm install -D @capacitor/cli
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
# APK will be at android/app/build/outputs/apk/debug/app-debug.apk
```

## Notes for next steps

- The app icon/splash screen are Capacitor's defaults for now — swap them
  later with `@capacitor/assets` once you have real artwork.
- The app ID is `com.timemint.app` and the display name is "Time Mint" —
  both set in `capacitor.config.json`, change them any time before your
  first real install.
